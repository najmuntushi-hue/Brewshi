# ☕ Brewshi

Brewshi is a modern and responsive coffee shop website designed to provide a warm and engaging online coffee experience. 
The website showcases a variety of coffee drinks, subscription plans, customer reviews,
and information about the Brewshi coffee experience.


## ✨ Features

- 📱 Fully responsive design for different screen sizes
- ☕ Coffee menu with different drinks and prices
- 🛒 Interactive "Buy Now" buttons
- 🎁 Promotional offer banner
- 💳 Coffee subscription plans
- ⭐ Customer reviews/testimonials
- 🌱 Why Choose Us section
- 📩 Contact form
- 📱 Responsive mobile navigation menu
- 🔗 Social media links
- 🎨 Modern coffee-themed UI design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts – Poppins
- Font Awesome

## 📦 Dependencies

Brewshi is a frontend-only project and does not require npm or any package manager.

External resources used:

- Google Fonts – Poppins
- Font Awesome 6.4.0
